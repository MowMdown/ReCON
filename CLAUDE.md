# ReCON

- Pull requests go into the `testing` branch, not `main`.
- Work on the `claude` branch. Before starting new work, make sure its last PR is merged, then reset it to `origin/testing`.
- The ReCON overhaul is developed on the `dev` branch: commit and push overhaul work there, not to `claude`.
- Don't open a pull request until asked to. Commit and push to `claude` as you go.
- Don't report commits, pushes or pull requests unless one fails.
